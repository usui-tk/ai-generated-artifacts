# .NET Framework release information - .NET Framework | Microsoft Learn

The .NET Framework updates include cumulative security and reliability improvements. We recommend that you apply updates as part of your regular maintenance routines.

.NET Framework will be supported with fixes and security updates for years to come as explained in more detail in the [lifecycle and support policy](/en-us/lifecycle/products/microsoft-net-framework). You can acquire the latest, most secure version of .NET Framework from Windows Update or by visiting Microsoft Update Catalog.
